서비스 약관 (Terms of Service)

최종 수정일: 2026-09-21

1. 서비스 개요

「Shorts Factory」는 소유자 1인이 자신의 PC에서 사용하는 개인용 데스크톱 도구입니다. 외부 사용자에게 서비스를 제공하지 않으며, 회원 가입이나 제3자 이용이 없습니다.

2. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 도구를 사용하는 것은 YouTube 서비스 약관에 동의하는 것을 의미하며, Google 개인정보처리방침이 함께 적용됩니다.

3. 데이터와 권한

도구는 소유자가 승인한 OAuth 권한으로 소유자 본인의 채널에만 접근합니다. 자세한 내용은 개인정보처리방침을 참고하세요. 권한은 언제든지 Google 계정 보안 설정에서 철회할 수 있습니다.

4. 책임

도구는 있는 그대로(as-is) 제공되며, 소유자 본인의 콘텐츠 업로드 용도로만 사용됩니다. 업로드되는 모든 콘텐츠에 대한 책임은 소유자에게 있습니다.
